# Фото дорожных знаков

Положите сюда сжатые фото знаков.

**Именование:** `КОД.jpg` или `КОД.png`

Примеры:
- `2.1.jpg` — знак 2.1
- `3.24.jpg` — знак 3.24
- `4.1.1.jpg` — знак 4.1.1

После добавления файлов сделайте commit и push (или просто залейте через GitHub web).  
Vercel автоматически задеплоит, и знаки появятся в приложении без нагрузки на Supabase.

Если файла нет — показывается SVG-версия знака.
